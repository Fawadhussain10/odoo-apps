Wires PackBytes HMS into pb_sms's SMS gateway so patients get texted automatically at the moments that matter, using company-configured, mail-template-rendered wording:
Patient Registered → Appointment Confirmed → Reminder Before Visit

👤 Patient Registration SMS

The moment a new patient record is created, a welcome text renders from the company's configured template and goes straight to their phone — a bad template raises a clear admin error instead of failing silently.

✅ Appointment Confirmation

Confirming an appointment fires an SMS built from the company's appointment-registration template, rendered with that specific appointment's own data via Odoo's mail-render engine.

⌛ Visit Reminders

The scheduled reminder job texts every upcoming patient with a phone number on file, using a separate reminder template so the wording can differ from the confirmation message.
