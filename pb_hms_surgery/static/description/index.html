Manages the full lifecycle of a surgical case — disease, classification and operative notes, consumable-kit tracking, and packaged surgery pricing — independent of, but ready to plug into, Hospitalization.
Draft → Confirmed → Done (or Cancelled)

🧉 Surgery Case Record

Each case tracks the surgery name, the disease it treats, an Optional/Required/Urgent classification, and special precautions — all locked read-only once the case is cancelled or done.

🔧 Kit-Product Consumption

Consumable line items model exactly what a surgery kit consumes — so booking a procedure that uses a suture kit or instrument tray automatically tracks the components used, not just a generic "surgery" charge.

📋 Operative Documentation

Diagnosis, clinical history, examination, investigation, discharge diagnosis, operative note and post-operative course are structured fields on the case, giving a complete operative record.

💰 Surgery Packages

Bundle multiple priced order lines into a Surgery Package with its own pricelist, currency and computed totals — useful for quoting a fixed-price bundle (e.g. "Appendectomy Package") instead of billing every line separately.
