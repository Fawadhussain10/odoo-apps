📱 Link by QR Code

Open Settings > Technical > WhatsApp. While no number is linked the QR code shows straight away — scan it from Linked devices and you are connected. No Node.js, no gateway.

🔢 Multiple Numbers

Link as many numbers as you need. Each keeps its own session, label, default flag and (optionally) company.

🧭 Asks Which Number

Every WhatsApp button opens a Send From dialog: pick the number, check the phone, edit the message, then send.

🛒 Sales Orders & Quotations

A WhatsApp button on the Sales Order sends the quotation or order as a PDF file to the customer.

🛍️ Purchase Orders & RFQs

Send an RFQ or purchase order PDF to the vendor straight from the Purchase Order form.

🚚 Delivery & Receipts

Send the delivery slip or receipt of a transfer to the customer or supplier from the Inventory transfer form.

🧾 Invoices, Credit Notes & Bills

The button appears on posted customer invoices, credit notes, vendor bills and refunds, with the amount and due date in the message.

👥 Salary Slips

Send a payslip PDF privately to the employee's mobile — a file in their chat, never a public link. Appears when Payroll is installed.

📒 Customer & Vendor Ledger

A WhatsApp Ledger button on the Contact sends an account statement PDF with a running balance. Built in — no Enterprise reports needed.

📎 PDF Attached, Message Editable

Documents go as real PDF files with your message as the caption. Untick Attach PDF to send text only.

🧩 Adapts to Your Apps

Buttons are added only for the apps you have installed (Sales, Purchase, Inventory, Payroll), so the module installs on any database.

📋 Message Log & API

Every message is logged with number, status and document. Developers can call send_message / send_messages from any module.

💬 WhatsApp Chat Screen

A premium, WhatsApp-style WhatsApp app on the Odoo home screen (visible only to the WhatsApp / Chat User group) lists the conversations Odoo started — only those, never the rest of the phone. Read replies as chat bubbles and answer right there.

🔔 New-Message Pop-up

When a reply arrives, a short “New WhatsApp message from …” pop-up shows for 2 seconds on any screen, with an Open button that jumps to the chat.

📷 Photos & Files

Received images, stickers, videos, voice notes and documents are shown in the chat (images inline), and you can send emoji, pictures, PDFs and files back with an emoji picker, paste and drag & drop. Replies arrive live over a websocket.

How to get started

  1. Install the Python library neonize==0.5.2 where Odoo runs, then install this module.
  2. Open Settings > Technical > WhatsApp > WhatsApp Numbers (developer mode) and scan the QR code with WhatsApp → Linked devices → Link a device.
  3. Open any Sales Order, Purchase Order, Transfer, Invoice, Bill, Salary Slip or Contact and click WhatsApp.
  4. Choose the number, review the phone and message, and press Send.
  5. Open the WhatsApp app on the home screen to read replies and chat with the numbers you have written to (give users the group WhatsApp / Chat User).
