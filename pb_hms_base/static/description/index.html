The shared foundation every PackBytes HMS module builds on — patient and physician master data, drug reference data, invoicing helpers, QR identification and appointment consumables — so every clinical module speaks the same data model.

🩺 Patient Master Data

Government ID, marital status, spouse/family details, education, occupation, religion, nationality and passport — one record every other HMS module reads from, with a birthday-email hook built in.

🩺‍⚕️ Physician Registry

Specialty, degrees and medical license per physician, each linked to a system user so scheduling, prescriptions and clinical notes all resolve back to a real practitioner.

💊 Drug Reference Data

Flavour, dosage form, active component (with amount + UoM), manufacturer and administration route as first-class reference lists, so prescriptions describe drugs precisely instead of as free text.

🧾 Invoicing Mixin

A shared `pb_create_invoice` helper that every clinical module (appointments, treatments, procedures) calls to turn a service line into a real Odoo invoice, with a per-record invoice-exemption flag.

🔧 Consumable & Stock Mixin

A reusable consumable-line model (product, UoM, lot/serial, quantity, price) plus a `consume_material` helper that posts the matching stock move when a service uses inventory.

🔑 QR Identification

A QR-code mixin any model can inherit to get a scannable unique code — used across the suite for fast patient/record lookup at the point of care.
