Auto-generates check-digit-verified EAN13 barcodes for products, with the numbering sequence configurable per product, per category, or company-wide — and optional automatic generation on product creation.

🏷️ Three-Level Sequence Fallback

A barcode sequence can be set on the product itself, its category, or the company; the generator checks each level in that order so you only configure it once at the level that makes sense.

⚙️ Auto-Generate on Create

A company setting turns barcode generation on for every new product automatically, so nothing ships without a scannable code.

🔄 Collision-Safe

Every generated barcode is checked against existing products before being assigned; on a collision it silently regenerates the next one instead of creating a duplicate.
