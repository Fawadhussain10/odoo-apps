Wires PackBytes HMS into pb_whatsapp / pb_whatsapp_meta so patients get WhatsApp messages at the moments that matter, with the full conversation visible from the appointment itself.

✅ Appointment Confirmation

Confirming an appointment renders the company's confirmation template with that appointment's own data and sends it straight to the patient's WhatsApp number.

⌛ Visit Reminders

The scheduled reminder job messages every upcoming patient with a phone number on file, using its own separate reminder template.

💬 Chat History on the Appointment

A "WhatsApp Chat History" action on the appointment pulls up the full message thread with that patient's linked contact — no jumping to a separate app.

🔄 Reschedule-Aware

Rescheduling an appointment is handled explicitly so reminder/confirmation logic stays correct against the new time rather than the original booking.
