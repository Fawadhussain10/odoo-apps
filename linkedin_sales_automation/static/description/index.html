LinkedIn Sales Automation

AI agents for Odoo 18 — Claude writes, Odoo sends within your rules
Odoo 18Community + EnterpriseNo Claude API keyOwn server or Odoo.shClaude Pro or higher
Prospect on LinkedIn with several accounts at once. Odoo finds people, sends invites and messages within your limits, reads replies and hands warm leads to Odoo CRM. Claude, through one connector URL and no API key, writes every note, message and post. Run it on your own server with the built-in LinkedIn engine, or on Odoo.sh with Claude in Chrome.
Features

What it does

Four AI agents
Connection and Chat Agent per persona, shared Follow-up and Activity Agents, each with Run / Pause / Stop.
Many LinkedIn accounts
One profile per account, each with its own engine or Chrome, personas and limits.
Built-in LinkedIn engine
Odoo installs and runs the open-source LinkedIn engine itself: no terminal, no server setup.
Claude writes
Notes, questionnaire messages, follow-ups, handoffs and posts. For each person it first reads their LinkedIn profile kept in Odoo, then their last reply, and only then writes.
Warm leads to CRM
At the pivot Odoo creates the CRM lead with the AI summary and answers, and hands the prospect to you.
Safe by design
Daily limits, send windows in each persona’s time zone, delay gaps, takeover, a fresh read before every send, and an automatic pause when LinkedIn’s invitation limit is reached.
Posts
Post ideas → Claude drafts → you approve → published at the chosen time, with reactions and comments read weekly.
Live dashboard and map
Account health, work queue, last Claude run, KPIs, funnel and a world map of your prospects, refreshed every minute.

Before you start

Requirements

  • Odoo 18 Community or Enterprise; standard dependencies only (CRM, Calendar, Discuss, Sales Teams).
  • A Claude plan with custom connectors (Claude Pro or higher). No Claude API key.
  • Built-in engine: a self-hosted Linux server (x86_64 or arm64) with internet access; about 1 GB of RAM per connected LinkedIn account while its engine runs (up to 1.5 GB at peaks) and about 1.1 GB of disk for the engine and its browser, shared by all accounts.
  • Built-in engine: the browser’s system libraries, installed once by a server administrator with the one command Settings shows (for example on Ubuntu 24.04: sudo apt-get install -y libasound2t64 libatk-bridge2.0-0t64 libatk1.0-0t64 libatspi2.0-0t64 libcairo2 libcups2t64 libdbus-1-3 libexpat1 libgbm1 libglib2.0-0t64 libnspr4 libnss3 libpango-1.0-0 libudev1 libx11-6 libxcb1 libxcomposite1 libxdamage1 libxext6 libxfixes3 libxkbcommon0 libxrandr2 xvfb).
  • Built-in engine: LinkedIn’s interface language set to English on each engine account (checked at Connect).
  • Claude in Chrome: Google Chrome with the Claude in Chrome extension on the computer that does the LinkedIn work.

How it runs

A day with each mode

Built-in engine
At 09:30 a scheduled Claude task writes the notes and messages Odoo prepared, in a few minutes. From 10:00 in each persona’s time zone Odoo sends them one at a time with the random delay gap, re-reading every conversation right before a message. It reads the inbox every hour and, while invites are pending, your newest connections every 15 minutes, so accepted invites show within about 15 minutes. When someone is invited or accepts, Odoo keeps their LinkedIn profile on the prospect, and Claude reads it before writing to them. New replies wait for Claude’s next run (13:30, 16:30), which analyses them and writes the next step. A reply from someone you took over becomes an activity for the salesperson. At the pivot Odoo creates the CRM lead and sends the handoff.
Claude in Chrome
With the computer on, a scheduled Claude task (or you) runs the Claude in Chrome prompt 1–3 times a day inside the working hours. Claude checks the account, then works through the items Odoo hands out — inbox, acceptances, invites, messages, posts — reporting each one. Odoo keeps every limit; nothing is sent outside the windows.
Rules Claude cannot break

What Odoo enforces

  • Daily limits per agent, optional weekly limit and total target.
  • Send windows and working days in each persona’s target time zone.
  • A random delay between sends on each LinkedIn account; one action at a time per account.
  • LinkedIn’s weekly invitation limit: Odoo reads LinkedIn’s own notice and pauses that account’s Connection Agents until next week. If LinkedIn stops recording invitations without saying why, they pause for a day and try again by themselves.
  • A person LinkedIn only lets you invite with their email address is followed instead (or flagged), without retries.
  • Before writing, Claude gets each person’s LinkedIn profile from Odoo and is told to read the profile first, then the last reply and its nature, and only then write.
  • A restricted account is paused and its owner told; an expired session asks for Reconnect.
  • Every message goes out only after a fresh read of its conversation; a new reply drops the queued text, and a message you write by hand on LinkedIn takes the prospect over.
  • Manual takeover stops every agent for that prospect only; do-not-contact applies across all personas.
  • A send with an unknown outcome is never repeated; the prospect is flagged for a person to check.
  • Engine accounts read at most 150 LinkedIn pages a day by default (searches, inbox, conversations, acceptances).
  • Follow-only profiles are followed instead of invited, if the agent allows it.
FAQ

Questions

The sign-in inside Odoo does not work, or LinkedIn asks for a security check.
Use Import session: on your own computer install uv, run uvx mcp-server-linkedin@4.26.2 --login, sign in, zip cookies.json and source-state.json from ~/.linkedin-mcp and upload the zip. Delete the zip afterwards.
The profile says Reconnect needed.
LinkedIn ended the session. Its agents pause and the owner gets an activity. Press Reconnect LinkedIn (engine) or sign in to LinkedIn in Chrome (Chrome mode), then run the agents again.
Invites stopped with “weekly invitation limit”.
That is LinkedIn’s own weekly cap, lower on new accounts. Odoo reads LinkedIn’s notice, pauses the account’s Connection Agents until next Monday and resumes them by itself. Messages to people who accepted keep going out.
Invites are paused for a day.
LinkedIn did not record invitations to two different people in a row and gave no reason. Odoo pauses that account’s invites for 24 hours and tries again by itself; leave it paused.
A prospect shows Taken over although I did not press the button.
Someone wrote to that person by hand on LinkedIn from the account. Odoo stops the agents for that person only so they do not talk over you. A manager can press Return to agents.
Replies are picked up slowly.
The inbox is read every 60 minutes by default. Set “Check inbox every” to 20 or 30 minutes in Settings and raise the daily read budget (for example 250), or ask Claude to answer replies now.
The acceptance rate does not count someone who is connected.
It counts invitations Odoo sent. People who were already your connections are shown beside it as “already connected” and are still handled by the Chat Agent.
Scheduled actions stop on a server with many databases.
Without workers, Odoo only runs scheduled actions for databases opened since its last restart. Run Odoo with workers (workers and max_cron_threads in the configuration file, plus the /websocket route in the proxy): its cron workers then go through every database.
Claude in Chrome keeps asking for permission.
Choose Always allow for linkedin.com (and your Odoo address) in the extension.
Claude says there is nothing to do.
Normal for engine profiles when nobody accepted or replied since the last run and no notes are needed: Odoo keeps working in the background. Ask Claude “did my invites go out?”.
The engine is stopped.
A watchdog restarts engines every 5 minutes, or press Start engine. Engines also stop on purpose when a session expires or LinkedIn restricts the account.
Odoo asks to set LinkedIn to English.
Engine accounts read LinkedIn by its English labels: change the language in LinkedIn’s settings, then press Test connection.
Claude does not see a new tool after an update.
Restart Odoo and upgrade the module, then in Claude open the Odoo connector and make sure every tool is enabled, or remove and add the connector again with the same URL.
Sending looks slower than planned.
One send at a time with the random delay gap: five invites take several minutes.
Can messages have line breaks?
Messages go out as one paragraph (LinkedIn would send on Enter); posts keep their line breaks.

Security and privacy

  • The connector URL holds a random token, stored hashed, shown once, revocable, and blanked out of Odoo’s request log.
  • Claude’s tools run as a technical user with their own access group.
  • Passwords and codes typed in the sign-in dialog are never logged or stored; the session stays in the engine’s own folder on your server (permissions 700).
  • Each engine listens on 127.0.0.1 only, on a random secret path, one per LinkedIn account.
  • The prospects map works offline: no map or geocoding service is called.
