Batch and lot-level pricing and expiry control for pharmacy stock, with barcode generation and expiry-driven locking layered straight onto standard Odoo Sales, Purchase and Inventory:
Product → Lot / Batch → Expiry State → Lock / Unlock

🏷️ Batch-Wise Pricing

MRP price set per lot/batch, not just per product — the same drug from two different purchase batches can carry two different sale prices.

⌛ Expiry State Tracking

Every lot computes its own Fresh / Near-Expiry / Expired state, and a scheduled cron sweeps and blocks lots that pass their use date automatically.

🔒 Lock / Unlock Lots

A dedicated wizard to manually block or release specific lots or serials from sale, independent of the automatic expiry cron.

📋 Medicine Expiry Report

Filter by date range and warehouse location for a printable PDF of everything expiring across the pharmacy.

📦 Manufacturer Reference Data

Manufacturer product name, code and URL captured per product for cross-referencing supplier catalogs.

🔧 Barcode & Invoice Integration

Built on the barcode generator and stock-move invoicing modules, so lot barcodes print on labels and scan straight into invoices and pickings.
