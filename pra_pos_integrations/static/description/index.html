Real-time fiscal invoicing for Odoo 19 Point of Sale under the Punjab Revenue Authority e-IMS — every validated sale is reported to PRA the moment it is paid, the fiscal invoice number comes back, and a verification QR prints on the receipt. Built to PRAL's “POS Component & eIMS” specification, sandbox and production:
POS Order → PRA e-IMS → Fiscal Invoice Number → QR-verified Receipt

📡 Real-Time e-IMS Reporting

Every paid POS order is pushed to PRA as it is validated. The call runs on the server during checkout and never blocks the cashier — a network hiccup just leaves the order queued for retry.

🧾 Fiscal Number & QR on Receipt

The PRA invoice number and a verification QR code are stored on the order and printed on the customer receipt, ready to scan in the PRA Sahulat app.

🏪 Per-Counter Registration

Each Point of Sale carries its own PRA POS ID, token and Sandbox / Production mode — configured right in the POS settings, so multi-branch businesses report each counter correctly.

🔄 Automatic Retry & Resync

A scheduled job re-sends any Not Synced or Failed order from the last few days, and a one-click Resync to PRA action sits on every order and in the PRA Invoices list.

💲 Payment Mode Mapping

Map each payment method to PRA's codes — Cash, Card, Gift Voucher, Loyalty Card, Cheque. When an order mixes modes, PRA is told it was a Mixed payment automatically.

↶ Returns & Credit Notes

POS refunds are detected and reported to PRA as Credit invoices, referencing the original sale's USIN so the return is tied to the invoice it reverses.

🏷️ PCT / HS Codes on Products

A PRA HS/PCT Code field on the product template and variant forms; the module normalises it to the bare 8-digit form PRA expects before every submission.

🧮 Tax-Accurate Payload

Per-line sale value, tax rate, tax charged, discount and totals are computed from the real POS taxes, so what PRA records matches the printed receipt to the paisa.

📋 Full Request / Response Log

The exact JSON sent and the PRA reply are kept on each order, with a PRA Invoices menu that lists Synced / Not Synced / Failed at a glance.
