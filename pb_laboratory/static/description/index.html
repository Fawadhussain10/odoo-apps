A full lab workflow — requests, per-test results with structured parameters, sample tracking and collection centers, external outsourcing and invoicing — with a patient portal view into results.
Lab Request → Test Result → Report → Invoice

🧪 Lab Requests

Multi-line requests — one line per test — with per-line pricing, special instructions and quantity, generating one result record per test.

📋 Structured Test Results

Each result carries its own test-case parameters with per-parameter values, not just one free-text report field.

🥼 Sample & Collection Center Tracking

Tests link to sample types and collection centers, with an option to share one sample across multiple tests that don't need separate draws.

⏱️ Turnaround Time & Sub-Tests

Each test type carries its own turnaround time and can trigger subsequent child tests automatically — a reflex panel, for example.

👨‍⚕️👩‍⚕️ Dual Physician Trail

Distinct Prescribing Doctor and Pathology Doctor fields keep who ordered a test separate from who approved the result.

🏥 Outsourced Testing

A vendor-bill link lets a request be sent to and billed by an external lab, alongside the patient's own invoice.

📊 Digest & Portal

Daily/weekly KPI digest mail, plus a portal template so patients can view their own results online.
