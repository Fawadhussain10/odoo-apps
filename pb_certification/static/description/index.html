Issues templated, sequence-numbered certificates to any customer, vendor, employee or user, and keeps a locked history of everything that's ever been issued.
Pick Template → Apply & Edit Content → Issue (Done, Sequence-Numbered & Locked)

📄 Reusable HTML Templates

Certificate wording is built once as a template and rendered onto a new certificate with a single click, using Odoo's own QWeb mail-render engine — so placeholders resolve against the real recipient.

🔢 Sequence-Numbered on Issue

A certificate only gets its official reference number the moment it's marked Done, keeping draft/working copies clearly separate from officially issued ones.

🔒 Locked History

Once issued, a certificate can't be deleted — only draft certificates can, so the issuance record stays a reliable audit trail.

🏷️ Tagged &amp; Searchable

Certificates can be tagged and are reachable with one click from the partner form, so a contact's full certificate history is never more than a click away.
