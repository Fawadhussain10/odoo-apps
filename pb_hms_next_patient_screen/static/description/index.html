A configurable "now serving" waiting-room display — point it at any model with a state field, map which fields mean physician / patient / cabin, and it renders a live, auto-refreshing queue screen at a public URL.

🖥️ Model-Agnostic Queue Screen

Pick any target model, then map which of its fields mean physician, patient, cabin and state — the same screen engine can drive from appointments, treatments, or any other queue-shaped model.

🔄 Auto-Refresh

A configurable refresh interval controls how often the public waiting-screen page polls for the next set of records, no manual reload.

🎯 State Filtering

A configurable list of states (e.g. waiting, in_consultation) decides exactly which records show up on the board and which don't.

🎨 Configurable Display

Toggle patient name/photo and cabin number independently, and set a custom color for the row currently in progress.

👥 Multi-Physician, Multi-Screen

Screens can be scoped to a subset of physicians, so a department can run its own dedicated waiting-room display.

🌐 Public URL

Each screen is reachable at its own public web page, ready to put up on a waiting-room TV without a logged-in session.
